## Application mobile ou application web : laquelle choisir ?

Si votre application doit surtout afficher des informations, faire un calcul,
remplir un formulaire ou guider un parcours, une application web installable
suffit dans la plupart des cas : un seul développement pour tous les téléphones
et les ordinateurs, aucune validation par un store, des mises à jour immédiates.
Une application publiée sur les stores se justifie quand vous devez être présent
dans l'App Store et Google Play, ou utiliser des fonctions du téléphone qu'un
navigateur ne permet pas.

<div class="overflow-x-auto">

| <span class="sr-only">Critère</span> | Application web installable | Application publiée sur les stores |
|---|---|---|
| Installation | Depuis le navigateur, en l'ajoutant à l'écran d'accueil | Depuis l'App Store ou Google Play |
| Validation par Apple et Google | Aucune | À chaque publication et à chaque mise à jour |
| Mises à jour | Immédiates, pour tous les utilisateurs | Après validation, puis téléchargement |
| iPhone, Android et ordinateur | Un seul développement | Une version par système, ou un outil commun aux deux |
| Sans connexion | Possible, si c'est prévu dès la conception | Possible |
| Fonctions du téléphone (notifications, appareil photo, localisation…) | Une grande partie, selon le téléphone | Toutes |
| Coût | Généralement moins élevé | Généralement plus élevé |

## Deux applications installables, à essayer sur votre téléphone

Je les ai conçues et développées pour des projets personnels, pas pour des
clients. Elles sont en ligne et gratuites : vous pouvez les installer pour juger
sur pièce.

- **[GypSum](https://cedric-ruiu.github.io/gyp-sum/)** — un calculateur de
  dosage d'eau et de plâtre pour fabriquer des moules en céramique. On saisit
  les dimensions du moule et de la pièce ; l'application donne les quantités
  exactes. Tout le calcul se fait sur l'appareil, aucune donnée n'est envoyée.
- **[DAB Trainer](https://cedric-ruiu.github.io/atm-trainer/)** — un simulateur
  de distributeur de billets, pour que des personnes en difficulté cognitive
  s'entraînent à retirer de l'argent sans aucun enjeu, à leur rythme. Il
  s'utilise directement sur tablette. Gratuit, open source et sans publicité.

## Comment installer une application web ?

Ouvrez l'application dans le navigateur du téléphone, puis :

- **sur Android**, avec Chrome : menu ⋮, puis « Ajouter à l'écran d'accueil »
  ou « Installer l'application » ;
- **sur iPhone**, avec Safari : bouton de partage, puis « Sur l'écran
  d'accueil ».

Son icône rejoint celles de vos autres applications, et elle s'ouvre en plein
écran, sans barre d'adresse.

## Pour quels projets ?

- **Un outil pour vos clients** — calculateur, simulateur, configurateur, prise
  de rendez-vous.
- **Un outil pour votre équipe** — suivi de chantier, inventaire, fiches
  d'intervention remplies sur place.
- **Un parcours guidé** — visite, jeu, entraînement, comme DAB Trainer.
- **Un espace réservé** — aux membres d'une association ou d'un club.

## Comment se déroule un projet ?

1. **Un premier appel.** Vous me décrivez l'usage : qui s'en sert, où, sur quel
   appareil.
2. **Le choix de la solution.** Application web installable ou publiée sur les
   stores : je vous explique ce que chacune implique pour votre projet.
3. **La définition du projet.** Écrans, fonctionnalités, données : pour un
   projet conséquent, je rédige un cahier des charges, le document qui fixe
   précisément ce qui sera livré.
4. **Le développement.** Vous essayez l'application sur votre propre téléphone
   au fil de son avancement.
5. **La mise en ligne.** Publication de l'application, et sur les stores si
   c'est le choix retenu.
6. **Le suivi.** Corrections, évolutions, mises à jour.
